### Citation style
- **APA 7th edition** (Taylor & Francis "TF-Standard APA"). REE follows T&F's default education-journal house style; the citation-style aggregators (Paperpile, scispace) tag REE as the T&F APA flavor. **[VERIFY on the journal's IFA page — the page either says "APA" or directs to the TF-APA style sheet.]**
- In-text: author-date, e.g., `(Yosso, 2005)`; multiple `(Yosso, 2005; Tuck, 2009)`; direct quotes require page numbers.
- DOIs required for all sources that have them.

### Reference list
- APA-7 reference list. Journal titles in italics. Hanging indent. Authors listed Last, F. M. up to 20 authors; 21+ use ellipsis + final author. DOIs as `https://doi.org/...` URLs (no "doi:" prefix).
- Issue numbers in parentheses, non-italic, after italic volume number: `*Race Ethnicity and Education, 8*(1), 69–91.`
- Books: publisher only, no city/state (APA-7 change from APA-6).

### Abstract
- T&F education journals typically cap at **200 words [VERIFY]** (some are 250). Unstructured/narrative abstract is standard for REE.
- 4–7 keywords required, comma-separated, in alphabetical or significance order (journal varies). **[VERIFY count requirement.]**

### Manuscript word limit
- T&F humanities/education journals typically run **7,000–8,000 words including references and notes [VERIFY exact figure].** Some allow up to 9,000. The IFA page lists the specific cap for REE.
- The cap usually includes abstract, main text, notes, references, tables, and figure captions.

### Section headings
- APA-7 heading levels (Level 1: centered bold; Level 2: flush-left bold; Level 3: flush-left bold italic; Level 4: indented bold ending in period; Level 5: indented bold italic ending in period).
- T&F also accepts the Word default heading styles (Heading 1, Heading 2, etc.) — the typesetter will reformat. The important thing is hierarchy clarity.
- Numbered headings (I, II, III, IV…) are not standard APA but are accepted as long as hierarchy is consistent. The typesetter usually strips the numbers. **June should consider whether to keep or strip the Roman-numeral section labels.**

### Figures and tables
- Tables inline in the manuscript at first submission is acceptable; figures can be inline or separate files. For final submission, T&F prefers:
  - Tables: editable in Word (not images of tables), placed where first mentioned with caption above.
  - Figures: 300 dpi minimum, captions below, separate high-res files (TIFF, EPS, PNG) at revision/acceptance stage.
- Captions number consecutively: Table 1, Table 2; Figure 1, Figure 2.

### Anonymization / double-anonymized review
- REE uses anonymous peer review with at least two referees (per journal's own description). **Most T&F education journals are double-anonymized [VERIFY single vs. double].**
- If double-anonymized:
  - Title page (with author info, affiliation, ORCID, acknowledgments, funding) submitted as **a separate file** from the anonymized main manuscript.
  - Strip all author names, institutions, and identifying acknowledgments from the main manuscript.
  - Self-citations: cite in third person ("Bloch (2026) found..." not "I have previously argued..."); do not blank out — the reviewer needs to evaluate citation context.
  - File metadata: clear author name from Word's File → Properties.
  - Anonymize Figure/Table source notes if they identify the author's institution.

### Cover letter
- Required. Should include: title, confirmation of original work not under consideration elsewhere, brief statement of contribution/fit with REE's scope, any conflicts of interest, suggested reviewers (optional), corresponding author contact.

### Required statements (in the manuscript or submission system)
- **Funding statement** — required, even if "no external funding."
- **Conflict of interest / Disclosure statement** — required, even if "no conflicts."
- **Ethics statement** — required if human-subjects research. June's paper is not human-subjects work (synthetic corpus + design documentation of her own teaching practice with no identified students), but she should include a short statement to that effect: "This study analyzed a synthetic test corpus and the author's own pedagogical design practice; no human-subjects data was collected; IRB review was not required."
- **Data availability statement** — increasingly required. T&F default: state where data/code can be accessed. The Autograder4Canvas repo URL fits here.
- **ORCID** — recommended, links on submission.

### Manuscript file format
- **Word (.docx)** preferred for first submission. LaTeX accepted at revision stage for some journals. **PDF is NOT accepted for first submission via ScholarOne.**
- Double-spaced, 12pt, 1-inch margins, page numbers, continuous line numbers (helpful for reviewers).

### Submission system
- **ScholarOne Manuscripts** via the link on the REE journal page. Authors must register an account.
