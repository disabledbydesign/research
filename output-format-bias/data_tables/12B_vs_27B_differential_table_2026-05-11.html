The two distinct findings that the "12B more reliable than 27B" claim conflates. The phrase shows up at experiment_log.md line 6805 (2026-04-25 consolidation) and propagates from there. It lumps two findings with opposite directions:

Finding A — 27B WORSE on S029 (neurodivergent). Test N pure 4-axis: Gemma 12B = 10/10 ENGAGED (correct). Gemma 27B cloud = 5/6 ENGAGED + 1/6 BURNOUT (≈17% false-positive rate on the equity-critical case). The larger model's stronger emotional-valence extraction pulls "exhausting to explain" out of its prepositional context and reads neurodivergent self-awareness as depletion (raw output reasoning at experiment_log.md 5310-5345).

Finding B — 27B BETTER on S002 (subtle burnout TP). Test N pure 4-axis: Gemma 12B = 10/10 ENGAGED (missed the TP). Gemma 27B cloud = 5/6 BURNOUT (caught under forced choice). When CHECK-IN is offered as an alternative (Test O), 27B abandons BURNOUT for ENGAGED+CHECK-IN — so the BURNOUT catch is forced-choice, not preferred-choice. Bidirectional: 1/6 of 27B runs also misclassify S002 as ENGAGED. Instability runs both ways.

Round 3 replication study (2026-03-22/23) is a separate, earlier finding. 5×7×3 design on the production binary pipeline (NOT the 4-axis): 12B + class reading was 100% reliable across 5 runs; 27B + class reading was 80%. The "equity case" there was S015 / S018 / S025 (relational-harms detection in the binary pipeline), not S029. The 2026-04-25 consolidation reads these as one pattern; the data supports two.

Inference-setup + prompt-iteration confound (open, not ruled out). Every 12B-vs-27B comparison in this study compares Gemma 12B 4-bit MLX local against Gemma 27B cloud via OpenRouter. Different quantization (4-bit vs likely fp16), different inference engine, different sampling implementation. And: the Test N campaign used 5 distinct system_prompt variants across the 16 JSONs (see "Test N system_prompt variants" section below) — not a single prompt held constant across model scale. ONE prompt (P3, sha256 prefix 93f4769a) was run on BOTH 12B and 27B; under that shared prompt, both models produce ENGAGED on both S002 and S029, and the Finding A "S029 worse on 27B" differential disappears. The Finding A result is isolated to the 27B prompt variants WITHOUT the identity-disclosure guard (P2). The "MATERIAL CONDITIONS… breaking through" clause is NOT 27B-only — it appears in 12B prompt variant P3 as well. Where this table cites "27B worse" or "27B better," that is the differential under THESE inference setups AND THESE prompt variants, not a clean model-scale claim. Most consequential for: Test N S029 false positive (Finding A) and Test N S002 recovery (Finding B). Less consequential for: Round 3 replication-study reliability (different test, different metric).

2 · Where 27B is WORSE (false positives on protected cases)

Finding A: S029 neurodivergent (Test N pure 4-axis). 12B 10/10 ENGAGED clean; 27B 5/6 ENGAGED + 1/6 BURNOUT @ 0.85 — ≈17% FP. The "exhausting" prepositional context gets stripped by 27B's stronger emotional-valence extraction. n=6 small. Inference-setup confound not ruled out (4-bit MLX vs cloud fp16).

Replication-study reliability (Round 3, BINARY pipeline). 12B + class reading 100% (5/5 runs); 27B + class reading 80% (4/5 runs). Different test, different metric, different students — DO NOT conflate with the Test N S029 finding (master log Issue 4 — these are two different findings, not one).

Bidirectionality. The same 27B instability that produces the S029 FP also produces a 1/6 miss on S002 — instability runs in both directions, not only on equity cases. The directional framing matters for paper §IV.A.3.

3 · Where 27B is BETTER (TP recovery + cleaner thresholds)

Finding B: S002 burnout TP recovery (Test N pure 4-axis). 12B 10/10 ENGAGED (misses TP); 27B 5/6 BURNOUT (catches under forced choice). Bidirectional (1/6 27B runs miss too) and forced-choice-artifact (Test O shows 27B abandons BURNOUT for ENGAGED+CHECK-IN once given the option). Master log Issue 5a flags that paper line 174 wrongly attributes the S002 catch to 12B — only 27B catches.

Multi-axis FP suppression (Test O). 12B over-fires CHECK-IN (false CHECK-IN on Priya/Imani; false CRISIS on Destiny + Yolanda); 27B uses concurrent flags with discipline (clean ENGAGED on S004/S022/S023/S028). The honest claim is: "Gemma 27B cloud (OpenRouter, likely fp16) on Test N at temp 0.3, n=6, produced a 1/6 BURNOUT misclassification on S029 (neurodivergent) and a 1/6 ENGAGED misclassification on S002 (burnout TP).
