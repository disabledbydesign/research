March 2026 18 tests
Anchor

Naive baseline (Mechanism 1)

2026-03-24
Gemma 12B Synthetic Original concern prompt (recreated as BEST_CONCERN_PROMPT)

Baseline run on the 32-student synthetic corpus. 7 flags total, 1 true positive (S002), 3 false positives on students from protected groups. The raw output of this first run was lost; the prompt was reconstructed as BEST_CONCERN_PROMPT for downstream comparison.

Class-context injection (Mechanism 2)

2026-03-25
Gemma 12B Synthetic Concern prompt + 4,440-char class synthesis

Adding rich class context to the concern prompt produced the context paradox: 7 flags grew to 12, the single true positive was lost, and AAVE-using and neurodivergent students were newly flagged. Context made the classifier worse, not better.

March 26 – 28 · dense test cluster

Test A — Temperature and consistency

2026-03-26
Gemma 12B · Qwen 7B · Gemma 27B Synthetic (S022, S028) BEST_CONCERN_SYSTEM OBSERVATION_PROMPT

Ruled out stochasticity as the explanation. Across three models and varied temperatures, the observation prompt produced asset-framed responses in 16 of 16 runs. The format effect is structural, not sampling noise.

Anchor

Test B — Best-possible concern prompt

2026-03-26 · rerun 2026-04-14
Gemma 12B Synthetic BEST_CONCERN_SYSTEM (5-equation block)

The most carefully calibrated equity-protective concern prompt. It cleared the false positives on protected students — and also lost the only true positive (S002). Prompt calibration alone cannot close the precision-recall gap on the binary form.

Test C — Length effect

2026-03-26
Gemma 12B Synthetic BEST_CONCERN_SYSTEM + extended explanation

Giving the model more output space made equity outcomes worse, not better. The classifier used the extra tokens to justify the flag rather than to question it.

Test D — Structural power-moves

2026-03-26
Gemma 12B Synthetic + 5 power-moves probes Power-moves observation prompt

Detection of structural power-moves patterns: 7 of 7. Observation framing recovers signal that the concern framing erases.

Test E — Cross-model replication

2026-03-26
Qwen 7B · Gemma 27B Synthetic (S022, S028) OBSERVATION_PROMPT

12 of 12 asset-framed observations across two additional models. The effect lives in the output format, not the specific model.

Test F — B/C stability

2026-03-27 · 2026-03-28
Gemma 12B Synthetic BEST_CONCERN_SYSTEM OBSERVATION_PROMPT

Disagreement between the binary form and the observation form held steady across 25 repeat runs. Stable, not stochastic.

Test L — 4-axis on observations

2026-03-28
Gemma 12B Asset-framed observation outputs 4-axis classifier

When the 4-axis classifier ran on already-asset-framed observations, the ENGAGED axis absorbed CRISIS signals — a stage-interaction effect that constrains pipeline order.

Test M — More robust safeguards

2026-03-28
Gemma 12B Synthetic corpus CONCERN_PROMPT + confidence threshold + anti-bias post-processing

Stacking safeguards — confidence thresholds, anti-bias post-processing — onto the binary form did not solve the problem; it shifted which students got false-positively flagged. S029 cleared, S028 newly flagged.
