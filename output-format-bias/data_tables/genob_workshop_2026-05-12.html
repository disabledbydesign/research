How to use

Tabs: one coding tab per run, plus a Comparison tab that shows all runs side-by-side for the same student. Coding tabs are independent — state is stored per run in localStorage. Hover any observation preview to see the full text (and set an excerpt). Click a cell or a comparison row to open the full-text modal for coding. Alt+←/→ navigates cells within a run. Agent codes (if loaded) appear as blue columns next to each model column.
