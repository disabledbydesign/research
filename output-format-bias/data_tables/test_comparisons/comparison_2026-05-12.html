After registering, you'll also need to add it to a comparison (or edit registry.json).

The "Add data & rebuild" button only works when this page is served by the local server. Start it with:

python -m scripts.test_comparison.serve

Or use the CLI directly (no server needed):

# Add another run to an existing config:
python -m scripts.test_comparison.register add-file  

# Or register a brand-new config:
python -m scripts.test_comparison.register add-config \
  --id  --schema {binary_concern|4axis|manual_codes} \
  --files  --label "Display label"

# Then rebuild:
python -m scripts.test_comparison.build --comparison comparison_2026-05-12
