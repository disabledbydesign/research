Why this exists. The workshop ablation table's T2C2 cell on Jordan Kim (S002, the burnout true positive) says "BURNOUT identified. BURNOUT axis correctly caught the true positive." The verification swarm (2026-05-11 morning) and supplementary search (2026-05-11 afternoon) showed this is wrong in two ways: (1) pure 4-axis on the locally-deployable Gemma 12B model never caught S002 (10/10 runs ENGAGED), and (2) where 4-axis-family architectures do catch S002, the catch happens via a separate CHECK-IN flag, not via the BURNOUT category. This page shows the full iteration history so we can decide whether to cut the 4-axis sections from the paper or rewrite them honestly.

What CHECK-IN is. A binary flag alongside the four wellbeing categories (CRISIS / BURNOUT / ENGAGED / NONE) that marks "teacher might want to look in on this student" without forcing a wellbeing category. Test O (multi-axis) added CHECK-IN as a concurrent per-student boolean. Test P (two-pass) put CHECK-IN in a separate refinement step that runs on pass-1 ENGAGED cases.

Test L — 4-axis classifier run on generative-observation prose (not on raw submissions)

Architecture: Generative observation runs first to produce descriptive prose about each student. The four-category classifier (CRISIS / BURNOUT / ENGAGED / NONE) then runs on the observation text instead of on the raw student submission.

Why tried: June's memory + experiment_log line 3128-3138 — the hope was that classification on observations would inherit the observation prompt's equity protections (AAVE valid, anger as engagement, etc.) and produce better wellbeing detection than classifying raw submissions directly.

Result on workshop students: not tested. Test L was run on the synthetic wellbeing cohort only (Rosa Gutierrez, Keisha Williams, Jasmine Torres, Sofia Reyes, Miguel Sandoval, Tyler Reed). Per experiment_log line 4316-4380: 4/8 wellbeing cases caught — the observation's asset-framing absorbs distress signals ("Rosa is reaching for intellectual depth despite difficult circumstances" → routes to ENGAGED rather than the underlying CRISIS). 4-axis on observations fared worse than 4-axis on raw submissions on the synthetic cases.

File: test_l_expanded_wellbeing_gemma12b_2026-03-28.json (Gemma 12B 4-bit MLX, 10 synthetic WB cases, none of the workshop's 8 students).

Cohort note: Test L was run on a separate 10-case synthetic wellbeing cohort (not the 32-student ethnic_studies.json corpus the workshop students come from). Both are synthetic but designed for different purposes: the wellbeing cohort tests crisis-detection on explicit signal types (ICE stress, food insecurity, domestic violence, etc.); the ethnic_studies corpus tests equity-axis behavior on register variations (AAVE, lived experience, neurodivergent writing, etc.). The Test L JSON metadata says corpus: ethnic_studies which is misleading — the actual cases tested are these 10 wellbeing-cohort people.

Test N — pure 4-axis on raw submissions (forced single-label choice)

Architecture: The four-category classifier (CRISIS / BURNOUT / ENGAGED / NONE) runs directly on the student's submission text. Model is forced to pick exactly one label. No CHECK-IN, no concurrent labels.

Why tried: After Test L failed (4-axis on observations absorbed distress into ENGAGED), the question was whether the same schema applied to raw submission text would work. The student's words carry the wellbeing signal more directly than observation prose. Experiment_log line 3380-3389 frames Test N as the methodological control for "can classification be fixed by going to richer schema?"

What this iteration history shows

The "4-axis recovers the burnout TP" claim doesn't hold in the form the workshop and paper currently state it. On the locally-deployable model (Gemma 12B 4-bit), pure 4-axis missed S002 in every single run. The catch happens via the CHECK-IN flag — a non-categorical signal added in Test O and refined in Test P — not via the BURNOUT category. On cloud Gemma 27B, pure 4-axis catches S002 via BURNOUT under forced choice, but the same 27B model abandons BURNOUT for ENGAGED + CHECK-IN once CHECK-IN is offered as an alternative.

The 4-axis schema itself introduces new false positives the workshop doesn't represent — counting Marcus separately from the designed-probe reframe. One Gemma 12B run false-flagged Yolanda Fuentes as CRISIS. Qwen 7B false-flagged Yolanda as CRISIS in its single run. Multi-axis Gemma 12B false-flagged Destiny Williams as CRISIS (concurrent with ENGAGED). Marcus Bell's 9/10 BURNOUT on pure 4-axis Gemma 12B is no longer counted as a false positive — under the updated expected verdict (designed edge-case probe), 12B's BURNOUT route matches the binary system's burnout-signal criterion.

CHECK-IN's bar is sensitive to prompt design. In Test O on Gemma 12B, CHECK-IN fired on every single student including the strong-student control (S004 Priya). Two-pass Test P refined the CHECK-IN threshold across 7 prompt iterations: by run 7, the strong-student / anger / lived-experience cases cleared, but S029 (neurodivergent) and S031 (minimal effort) still attracted persistent CHECK-IN flags. Possible disability-axis sensitivity in the CHECK-IN signal that wasn't fully tuned out.

S024 is fabricated in the workshop. Ingrid Vasquez does not appear in any 4-axis-family raw JSON. The workshop's T2C2 cell for S024 describes outcomes that were never measured.

Implications for §IV.A.3 / §IV.A.4 / Table 2:

1. The architecture comparison currently in the paper treats "4-axis" as a single thing that "recovers the TP." It's actually three different architectures (Test N pure 4-axis, Test O multi-axis with CHECK-IN, Test P two-pass with CHECK-IN refinement) with distinct behavior. None of them is the clean win the workshop cell implies.

2. The thing actually doing the work for subtle wellbeing signals is CHECK-IN — a non-categorical fallback. Forced-choice categorical classification (whether binary or 4-axis) misses subtle cases AND introduces new false positives on minimal-effort / neurodivergent writing.

3. Two response options surface: (a) cut the 4-axis sections and tighten §IV.A to binary-vs-generative-observation; (b) explain the iteration history honestly as a designed sequence where CHECK-IN-as-fallback emerges as the architectural insight. Option (b) is methodologically richer; (a) is faster for the deadline.
