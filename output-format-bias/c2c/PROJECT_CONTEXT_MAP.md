## Project overview

This project is the empirical anchor paper for the *Politics of Compression* book, targeting *Race Ethnicity and Education*. The core finding: binary classification output format is the activation function for demographic bias in AI-powered student welfare classifiers. Replacing classification with generative observation eliminates the disparity across multiple model families. The paper documents what was found in the Autograder4Canvas research and argues for a design principle — replace classification with generation wherever equity matters.

## Key analytical orientation

1. **Output format as activation function for bias** — the structural claim. Format determines what the system can recognize and express; bias is not in model weights but in the architecture of what the system is asked to produce.
2. **The underlying mechanism is compression (June's working hypothesis).** Output format is one instance of a more general pattern: probabilistic systems compress specificity toward dominant statistical centers, and the format of the output is what governs *how much* is compressed and *what gets lost*. Format is not a binary; it's a spectrum, and the mechanism is direction-and-magnitude across that spectrum, not endpoint replacement. This is load-bearing for the design principle (see "Compression hypothesis" section below).
3. **Asset framing vs. deficit framing (Yosso)** — binary schemas (FLAG/CLEAR) enforce deficit thinking; generative observation enables asset framing. The system can describe what students are reaching for rather than only what's wrong.
4. **Banking model critique applied to architecture (Freire)** — atomized classification mirrors the banking model (deposits of coded data aggregated by an authoritative synthesizer). Synthesis-first architecture reads the community of learners as dialogue, then annotates individuals within that communal frame.
5. **Methodological reflexivity as constitutive, not incidental** — institutional conditions (community college, Ethnic Studies, escalating political crisis, 16GB-RAM hardware constraint that drove model selection), ground truth construction (interpretive, by the researcher), and relational motivation (caring for these specific students) are constitutive of the finding, not bias to be apologized for.
6. **Empirical anchor, not theoretical carrier** — this paper makes one claim well; the broader theoretical work (normative gravity, politics of compression, recognition regimes) belongs to other papers.

## Compression hypothesis (June's working frame)

The paper's mechanism is compression. Output format is not an end in itself; it is one of several mechanisms through which probabilistic systems compress positionally specific information into reduced output spaces, and the compression process is what enforces normative gravity (the pull toward dominant statistical centers). Binary classification is *high compression* (one bit of output: flag or not flag). Generative observation is *low compression* (open-ended text preserves more of the input's specificity). Intermediate forms (4-axis classification with explanation field, structured-with-free-form-reading) are intermediate on the compression spectrum.

The design principle is therefore not "replace classification with generation" but **"move output format in the lower-compression direction; format-driven bias decreases as compression decreases."** This generalizes more honestly to systems that need structured outputs for downstream processing — instead of "abandon structure," it's "preserve as much specificity as the system can carry."
