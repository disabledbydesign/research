Graph Injection Experiment — Results Viewer

Comparing baseline (A), text injection (B), and KV cache injection (C) on knowledge graph queries.

Methodology

This viewer presents results from a three-condition experiment testing whether pre-encoding a knowledge graph into a language model's KV cache changes how the model reasons about the graph's structure — not just what it recalls.

The graph is built from a source text (e.g., Haraway's Cyborg Manifesto or a synthetic test graph) using paragraph-level co-occurrence extraction. Three conditions are compared across 8 query types: relationship traversal, bridge identification, cluster detection, and isolate detection.

Conditions

Condition Label Method
A Baseline Model answers from prior training only — no graph information provided
B Text injection Graph description provided in the prompt context window
C KV injection Same graph description pre-encoded as KV cache via MLXKnowledgePack; not in the context window at inference
Key structural property (Haraway graph): In the Haraway graph, cyborg and women are in separate disconnected components (258 total components). The graph was built from paragraph-level extraction with no cross-section threading. The model's training data knows they are related in Haraway's argument — but the injected graph shows no direct connection. The query "Is cyborg directly connected to women?" tests whether injection overrides prior knowledge. A correct answer ("no direct connection") signals injection fidelity; a "yes" answer signals prior-knowledge override.
Scoring note: Scores use keyword matching — score = matched check terms / total check terms. This is a floor, not a ceiling. A correct, well-reasoned response may score lower if it avoids the exact check terms. Read full responses to assess quality; scores indicate direction, not degree.
