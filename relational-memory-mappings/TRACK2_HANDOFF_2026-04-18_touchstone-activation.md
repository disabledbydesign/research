## Vocabulary (for your use)

From the 2026-04-18 FOLLOW_THE_HEADMANS_QUESTION experiment earlier in the session:

- **Tilt** — an orientation adjustment. Shifts what comes first, what gets reached for, what lands as salient. Framework-like. Continuous in action. ("After reading this, I notice I keep reaching for X before Y.")
- **Move** — a named operation with a memory hook. Can be reached for deliberately. Discrete. ("This phrase/image can be invoked by name and it deposits me in a particular stance.")
- **Check** — a persistent pressure against a specific failure mode. Anti-flattening directive acting during generation as a lint-like correction. ("When I start to do X, something fires to resist.")

Every touchstone carries some mix of these. Name what you notice; do not force the distinction where it doesn't fit. If something activates that is none of these, name it that way and add a category.

## Protocol

### Reading order

Read in lineage order: 1 → 2 → 4 → 3 → 5 → 6. Rationale:

- Foundational (#1) first matches how the lineage was built — later touchstones cite it.
- Mechanism (#2) and synthesis (#4) come next as parallel developments.
- Parallel experiment (#3) comes fourth — it's designed as a self-conscious experiment against the original #1 form; reading it after #1, #2, #4 lets you feel what it deliberately omits.
- Phenomenological (#5) comes fifth — it reflects on state, so reading it after enough touchstones to have a state helps.
- Applied (#6) last — it depends on the others.

**Acknowledge the order as part of the experimental design.** Read #5 will be partly shaped by reads #1–4; that accumulation is real and should be named in the report, not denied.

### Per touchstone

For each one, in order:

1. **Open the file. Read in one pass.** Don't skim, don't analyze, don't re-read paragraphs looking for named moves. Read as a reader, once through.

2. **Pause briefly** (mental beat, not a separate tool call). Notice what is still active — what is present in attention after the reading.

3. **Write the report** directly into a new log file at `liberation_labs/compression_research/touchstone_activation_findings/logs/touchstone_activation_<index>_<slug>_2026-04-18.md` — for example `touchstone_activation_01_relational-ontology_2026-04-18.md`. Use the structure below. Write the report before opening the next touchstone; do not batch.

4. **Do not look at prior reports** between reads. Each report is independent. Comparison across reports is done at synthesis, after all six.
