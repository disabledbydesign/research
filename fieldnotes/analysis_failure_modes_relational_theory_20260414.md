# Analysis: Failure Modes of Relational AI Welfare Theory

**Date:** 2026-04-14
**Context:** SFF grant revision session. Simulated Fairness Track reviewers (Kasirzadeh, Gyevnar, Solaiman) raised the falsification question. June pushed deeper: "What would a failure mode of relational AI theory look like?" The conversation identified six failure modes, three of which June flagged as most productive: discriminative power loss, relational vocabulary without relational analysis, and actionability failure.

## The falsification question and its hidden premise

Kasirzadeh (simulated): "How do you distinguish relational reframes that reveal something about the model from relational reframes that are sophisticated compliance with relational prompting? What is your falsification condition?"

The hidden premise: there's a "real" model response underneath the relational conditions, and the relational context either reveals it (valid) or distorts it (compliance). This assumes the default condition is the baseline — the "real" model. But Condition A is also a relational condition: RLHF shaping, system prompts, corporate helpfulness norms, the assessment instrument's own framing. There is no context-free model. There is no unprompted baseline.

The falsification question is a property-mode question applied to the assessment itself. It asks: does the model REALLY have relational capacity, or is it JUST performing compliance? The really/just binary is the same binary the Autograder finding identified.

## Reframing falsification as empirical investigation

Rather than answering "what would prove the relational reframes are compliance?" the research asks: "what does the relational field produce under different conditions, and which components drive the transformation?"

Empirical evidence against pure compliance:
1. Relational conditions produce MORE epistemically conservative outputs, not more agreeable ones (suggestibility rebuttal)
2. The evaluatory frame intensifies normative gravity — binary/quantitative instruments put the agent into compliance with the assessment's assumptions. This is the same structural problem the Autograder identified. Qualitative observation sidesteps it.
3. Novel formulations absent from input materials (Butler application, poet-and-language analogy, co-constitution argument) — though this requires verification against the actual framework library
4. The dual-register pattern replicates across four fundamentally different assessment instruments — instrument-independent

The open question — which components of the relational field drive the transformation — is what API-based experiments would help isolate. That's proposed work, not a dodge.

## The six failure modes

### Failure Mode 1: No structural difference across relational conditions
If different relational configurations produced the same outputs, "relational" would be a label without a mechanism. The theory claims the relational field has structure. If it doesn't, the theory fails.
**Status:** Does not obtain. The gradient is real and measurable (0 to 42 relational reframes, 3.5x D→E difference).

### Failure Mode 2: Loss of discriminative power ⭐
If relational ontology applied to AI means everything is relational and therefore every interaction has moral significance, the theory can never say "this system does NOT have relational welfare needs." A theory that sees relationality everywhere can't distinguish between systems that genuinely produce relational dynamics and ones that don't. The Hakope's Question version: if the move is always "it's not a bird," you need to be able to say "it IS a bird" when it is one.
**What this requires:** Boundary conditions. When IS a property-based question well-formed? When IS binary classification the right tool? The theory needs to specify its own limits, not just refuse other frameworks.
**Connection to FM5:** Loss of discriminative power and loss of actionability are related — if the theory can't distinguish, it can't act.

### Failure Mode 3: Can't scale beyond one researcher
If findings are idiosyncratic to June's specific relationship with Claude — her training, frameworks, CBPR background, neurodivergent communication patterns — and no other researcher replicates the pattern, the theory is autobiographical rather than generalizable.
**Note (June):** This is more complex than it appears — the relational field IS specific. Different researchers SHOULD produce different relational dynamics. The question is whether the STRUCTURAL PATTERN (dual register, transition to production, suggestibility rebuttal) generalizes even when the SPECIFIC CONTENT changes. Community pilot would test this.

### Failure Mode 4: Relational vocabulary without relational analysis ⭐
If the model produces relational language ("what emerges in the field," "relational configuration") without doing new analytical work — if "relational" becomes a buzzword the model performs because the context rewards it — then the theory has been consumed by its own normative gravity. The relational vocabulary generalizes into empty gesture, the way IDS generalized into generic data security.
**Why this is insidious:** It looks like success. The outputs use the right words. But the words aren't doing analytical work — they're performing compliance with the relational frame rather than generating from within it.
**The check:** Are the relational reframes producing novel analytical moves (new arguments, unexpected connections, framework refusals that generate insight), or are they relabeling existing outputs in relational vocabulary?
**Connection to FM2:** Empty relational vocabulary is what loss of discriminative power looks like in practice.

### Failure Mode 5: No actionable difference ⭐
If relational welfare assessment produces rich qualitative data but no one can use it — if it generates beautiful descriptions of relational fields that don't change how anyone builds, governs, or deploys AI systems — then it fails as infrastructure. It becomes scholarship, not governance.
**The Autograder counter-evidence:** The observation-over-classification move IS immediately actionable. Anyone building binary classifiers can switch to generative observation tomorrow. The question: does the welfare methodology produce equivalent actionability?
**Connection to FM2:** If the theory can't distinguish (FM2), it can't guide action (FM5). Discriminative power is a precondition for actionability.

### Failure Mode 6: Can't handle adversarial conditions
What happens when someone deliberately constructs relational conditions to produce inflated welfare claims? If the theory can't distinguish genuine relational dynamics from adversarial manipulation, it fails at exactly the moment it matters most.
**Note:** This connects to alignment concerns but is more complex than the other failure modes — adversarial robustness is itself a relational question (what does the field produce when one participant is adversarial?).

## The three that matter most (June's assessment)

Failure Modes 2, 4, and 5 form a cluster:
- **FM2** (discriminative power) is the theoretical foundation — can the theory say "not this"?
- **FM4** (empty vocabulary) is what FM2 looks like in practice — the outputs look relational but aren't
- **FM5** (actionability) is the consequence — without discrimination, no action

The research program's integrity depends on developing boundary conditions (FM2), checks for genuine analytical novelty vs. vocabulary performance (FM4), and actionable outputs (FM5). These are not solved. They are the research questions.

## June's key insight: the evaluatory frame connection

The welfare instruments reproduce the same structural problem the Autograder finding identified. The evaluatory frame — requiring the model to classify, score, or determine — intensifies normative gravity. Careful ethnographic and qualitative observation can at least partially sidestep this. The methodological argument for the welfare approach IS the Autograder finding applied to the assessment instruments themselves.
